     FPT MVNO - HỆ THỐNG CẬP NHẬT TỰ ĐỘNG BẢNG VÀNG THI ĐUA SIM FPT 3 TUỔI (SCT)

1. CẤU TRÚC CÁC FILE CHẠY CHÍNH (NGOÀI THƯ MỤC GỐC):
   ├── CHAY_CAP_NHAT.bat  <-- [CHÍNH] Nhấp đúp vào đây để cập nhật Infographic hàng ngày.
   ├── KEO_LEN.bat        <-- [ĐẨY LÊN] Đẩy code & dữ liệu mới từ máy này lên GitHub.
   ├── KEO_VE.bat         <-- [KÉO VỀ] Tải toàn bộ bản cập nhật mới nhất từ GitHub về máy.
   ├── input_data/        <-- Thả file Excel báo cáo mới vào đây.
   ├── output/            <-- Nơi nhận file ảnh nét cao (KetQua_ThiDua_Sim.png) và web.
   ├── template/          <-- Mẫu giao diện & tài nguyên đồ họa Ultra-HD.
   └── scripts/           <-- Bộ mã tự động hóa (PowerShell).

----------------------------------------------------------------------------------------
2. CÁCH SỬ DỤNG TRÊN MÁY THỨ 2 (HOẶC ĐỒNG BỘ GIỮA 2 MÁY):

   👉 BƯỚC A: Cài đặt lần đầu trên Máy thứ 2
      1. Trên Máy 2, mở trình duyệt vào link GitHub:
         https://github.com/bachhue128-create/SCT
      2. Bấm nút màu xanh "Code" -> Chọn "Download ZIP".
      3. Giải nén file ZIP ra màn hình Desktop (đặt tên thư mục là SCT hoặc THI_DUA_SIM_FPT).
      => Xong! Máy 2 đã có toàn bộ hệ thống sẵn sàng.

   👉 BƯỚC B: Khi làm việc trên Máy 1 xong, muốn Máy 2 có dữ liệu mới:
      - Trên Máy 1: Nhấp đúp vào file "KEO_LEN.bat" (Hệ thống tự động đẩy toàn bộ lên GitHub).
      - Trên Máy 2: Nhấp đúp vào file "KEO_VE.bat" (Hệ thống tự động kéo bản mới nhất về).

   👉 BƯỚC C: Ngược lại, nếu làm việc trên Máy 2 muốn chuyển sang Máy 1:
      - Trên Máy 2: Nhấp đúp vào file "KEO_LEN.bat".
      - Trên Máy 1: Nhấp đúp vào file "KEO_VE.bat".

   * Lưu ý lần đầu bấm "KEO_LEN.bat" trên máy mới: 
     Hệ thống sẽ hỏi mã Token 1 lần duy nhất, bạn chỉ cần dán mã token GitHub vào và Enter.
     Những lần sau chỉ việc bấm đúp là xong, không cần nhập lại!

----------------------------------------------------------------------------------------
3. CÁCH CẬP NHẬT INFOGRAPHIC MỖI NGÀY:
   - Bước 1: Copy file Excel số liệu mới vào thư mục "input_data" (tự nhận diện file mới nhất).
   - Bước 2: Bấm đúp chuột vào file "CHAY_CAP_NHAT.bat".
   - Bước 3: Xem kết quả! File ảnh "KetQua_ThiDua_Sim.png" tự động mở lên màn hình.
